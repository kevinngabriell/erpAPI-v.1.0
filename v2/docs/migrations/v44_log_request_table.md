# Aluria Schema Migration — v44: request/error logging (table already exists)

The `log_request` table already exists in `CORE_SCHEMA` — it was created by `movira_api` as part of its `RequestLogger` system. This migration documents the ERP API's adoption of that existing table for structured request/error logging.

## Summary

Every API response now includes an `error_id` (the `request_id`) on error responses (HTTP >= 400). The full request metadata — endpoint, method, status code, outcome, error code/message, duration, IP, user agent, and complete exception details (class, message, file, line, stack trace) — is logged to the existing `log_request` table via a `register_shutdown_function`. When the database insert fails (e.g. connection lost), the log falls back to a JSONL file at `v2/storage/logs/request-{date}.jsonl`.

The ERP API's `flushRequestLog()` in `v2/helpers/error_handler.php` inserts into the existing table using these columns: `request_id, client_request_id, timestamp, api_version, endpoint, http_method, status_code, outcome, level, error_code, error_message, retryable, client_type, username, app_id, company_id, ip_address, user_agent, duration_ms, db_connected, memory_peak_kb, exception_class, exception_message, exception_file, exception_line, stack_trace`.

## Production environment (`movira_core`)

**Already applied by movira_api.** The same `log_request` table exists in production as part of the movira_api deployment. No additional DDL needed.

## Verification

```sql
-- Confirm table exists
SHOW CREATE TABLE `movira_core_dev`.`log_request`;

-- Confirm columns
SELECT COLUMN_NAME, DATA_TYPE, IS_NULLABLE, COLUMN_DEFAULT
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = 'movira_core_dev' AND TABLE_NAME = 'log_request'
ORDER BY ORDINAL_POSITION;

-- After a test request, confirm a row was logged
SELECT request_id, endpoint, http_method, status_code, outcome, level,
       error_code, error_message, duration_ms, ip_address, timestamp
FROM `movira_core_dev`.`log_request`
ORDER BY timestamp DESC LIMIT 5;
```
